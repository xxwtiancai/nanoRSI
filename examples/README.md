# Examples and published studies

- [`results/`](results/) — every published study, kept unchanged as evidence. Studies on the
  current v0.5 core: [harness2-lab-nanorsi](results/harness2-lab-nanorsi/README.md). Studies
  that used the paper's own code for comparison: [harness2-lab-opencode](results/harness2-lab-opencode/README.md)
  (faithful run) and [harness2-lab](results/harness2-lab/README.md) (stdlib pilot). Everything
  else under `results/` ran on the v0.4 core.
- [`lab_opencode/`](lab_opencode/README.md) — the LAB + OpenCode executor and judge behind the
  v0.5 runner/judge command protocol.
- [`v0.4/`](v0.4/) — task packs, runners and demos of the v0.4 core (BBH, ALFWorld, HumanEval,
  coding, parameter learning, remote workers, selector tooling, the harness2 stdlib pilot).
  They document the historical studies and no longer run on the current core.
