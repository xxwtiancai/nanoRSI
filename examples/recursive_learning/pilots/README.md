# Validation-only development evidence

All 48 configurations and all 576 policy/seed trials are retained: 24 configurations with global priorities, followed by 24 with within-class priorities and fixed empirical class mass. Only TRAIN and validation rows were scored. The source text and settings are retained inside each JSON; these unsigned development extracts are not nanoRSI HMAC journals. The final implementation was independently checked against the prototype on validation-only CLI runs before confirmation.

The strong-priority global pilot often weakened the frozen sampler versus uniform; those unfavorable controls are included. The selected confirmation settings are documented in the [study guide](../README.md). No confirmation test scores were used for their selection.
