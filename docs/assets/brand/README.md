# nanoRSI brand assets

Hero and mascot generated with the built-in image_gen tool for this project. They are illustrations, not product screenshots or model-performance evidence.

Visual direction: warm ivory, vermilion orange, charcoal; original terminal robot, a skill document and an iteration arrow. The hero's background was edited with image_gen to remain legible in both GitHub themes. The mascot retains its generated transparency.

## Readme presentation references

The layout borrows conventions rather than artwork or copy: a memorable first image and accessible starter path from [nanoGPT](https://github.com/karpathy/nanoGPT) and [nanochat](https://github.com/karpathy/nanochat); concise highlights and executable examples from [uv](https://github.com/astral-sh/uv); approachable agent framing from [smolagents](https://github.com/huggingface/smolagents). All nanoRSI brand illustrations are original generated assets.

GitHub API snapshot on 2026-09-09: nanoGPT 62,915 stars; nanochat 57,873; uv 89,632; smolagents 29,239. These numbers describe reference repositories, not nanoRSI.

## Hero background revision

The initial hero was transparent. The built-in image tool filled the entire background with opaque warm ivory while preserving the layout, lettering and mascot. The final alpha channel was checked to be fully opaque for theme-independent readability.
